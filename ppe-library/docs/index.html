A SMALL FIRST STEP

From install to a complete cycle.

Run a tiny quadratic problem before connecting your data. All three training phases run locally.

  1. 1

    Install from the repository

    Use Python 3.11 and run the command from the PPE repository root.

  2. 2

    Try the download-free demo

    Three regression objectives share one model. With --interactive, choose objectives and values after initialization, then navigate again after each cycle. Enter q to finish.

  3. 3

    Bring your own problem

    Copy the starter to my_experiment.py, add your model, train/validation/test loaders, and one loss per objective. Three, five, or more objectives use the same interface. Follow the dataset guide →

TERMINAL
git clone https://github.com/aamakor/PPE.git
cd PPE
python -m pip install -e ./ppe-library

# Choose preferences after initialization:
ppe demo --interactive --output runs/interactive-demo

YOUR PREFERENCES, EXPLICITLY

Tell PPE what to reduce.

A negative weight selects an objective to reduce and positive weights for objectives to increase. Zero leaves it unselected. PPE uses this direction in the predictor and retains its constraint checks.

This builder produces a ScriptedInteraction object using nonnegative slider magnitudes. In the default terminal interface, select objectives (for example, 13), then enter values (0.7 0.3); PPE constructs [-0.7, 0, -0.3]. Training and feasibility checks happen when you run PPE.

Model and data.
The PPE algorithm.

PPE brings the predictor–corrector algorithm to your PyTorch project through configurable datasets, models, objectives, paths, and interactive plots.

The current training core requires at least three objectives and four training batches. Use three or more objectives; choose any three for the plot while training on all of them.
